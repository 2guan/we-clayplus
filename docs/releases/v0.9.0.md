# we-clay v0.9.0

## 新增

- 提供 macOS、Windows、Linux 的预编译主程序和一键安装脚本。主程序内含 Dashboard、AI 与 gateway；仅 core 保持独立进程。
- 使用同一个运行授权 Key 下载 we-clay 与 core 的私有 OSS 产物，不再要求最终用户持有 OSS AK/SK 或 Go 源码访问权限。
- 六个平台构建、版本清单、大小和 SHA-256 校验由私有仓库的发布流水线完成；安装失败保留旧版本与旧授权文件。
- 支持指定原 core 账号目录和多套实例端口；主程序默认不启动外部插件，需要时可显式开启。

## 兼容性与使用

- `gateway.Run` 与现有 SDK 导入方式保留。已有 OSS 只读凭据下载方式仍适用于受控部署。
- 升级已有微信设备时，使用原账号目录作为 `--core-data-dir`；先停止旧 gateway，再启动新主程序。独立 core 可保持登录。
- 安装命令及 Windows、macOS、Linux 示例见[一键安装指南](../一键安装.md)。

## 发布前提

发布流水线需要 `we-clay/we-clay` 仓库的 OSS Actions Secrets，并且线上授权服务已部署下载接口。私有 OSS 中的二进制不作为 GitHub Release 附件公开分发。

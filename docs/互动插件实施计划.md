# 13 项互动插件实施计划

本次授权实现谁是卧底、狼人杀、阿瓦隆、剧本杀、默契测试、心动剧场、深夜电台、随机副本、文字跑团、每日抽签、趣味性格测试、群日报/周报、群梗博物馆。秘密通信统一使用好友私聊，不新增公开领身份页面，不修改 core。

## 实现边界

- 注册 13 个独立插件，各有开关和会话名单，真实模式默认关闭。公共工作台管理对局、失败回合、群梗审核和模拟操作。
- 多人局使用群内报名 + 私聊确认入局。只接受原群报名的稳定成员 ID；好友记录与实际私聊入站同时成立才确认可达。开局秘密发放期间暂停公开游戏，失败或结果未知不可冒充成功。
- 谁是卧底提供描述、投票、平票重投、出局猜词；狼人杀提供 6—12 人基础板子、夜间技能、狼人密聊、白天投票及猎人；阿瓦隆提供组队、审批、任务、五次拒绝和刺杀。
- 剧本杀使用固定快照保存角色、线索和答案；搜证逐步开放，秘密线索只私聊本人。副本/跑团的属性、背包、地图、骰点和战斗由程序管理。默契与性格测试通过程序计分。
- 模型请求沿用模型中心流水线、故障切换和一次完整流水线重试；结构不合法视为失败。身份与答案不进入公开任务结果。模型无真实操作工具。
- 群内真实 @ 开局，每会话仅一个活动互动局，并与海龟汤互斥。私聊秘密命令带对局码，多个群局不会串线。公开游戏进入普通上下文并标记；秘密操作排除出普通上下文，所有游戏消息排除长期记忆。
- 对局和待发消息事务保存，按对局串行执行，发出状态逐条保存。重启中断的生成可人工重试，发送结果未知必须人工核对，不自动重发。账号、epoch、插件权限、来源撤回及对局版本在执行前重新校验。
- 群日报按北京时间当天或最近七天读取本群归档，提供来源，容量不足明确失败；群梗必须引用有效来源，提交后待后台确认，支持拒绝和删除。
- 抽签按账号、会话、玩家、北京时间日期缓存；剧情/电台有独立记录。语音仅在已配置能力下扩展，本次交付文字交互完整闭环。

## 验证与回滚

验证规则引擎完整胜负流程、私聊身份隔离、群来源和报名限制、账号切换、重启恢复、未知发送不重发、模型失败与重试、上下文/记忆隔离、日报来源、群梗审核及后台移动端交互。使用虚构数据和本地模型模拟，不执行真实微信写操作。

只增加独立数据表和配置。关闭新插件即可停用；保留原始归档和海龟汤。未获更新本地应用指令前不重启当前服务。

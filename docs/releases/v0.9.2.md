# we-clay v0.9.2

## 独立 core

- 进程记录现在保存 core 启动时使用的账号数据目录。gateway 复用独立 core 前会核对该目录，避免移动目录后继续连接一个无法保存收件状态的进程。
- 旧版进程记录没有目录字段时，gateway 会读取运行中 core 的启动参数进行核对；路径相同才迁移记录。路径不一致会明确报错，并保留正在运行的 core 与登录会话。

## 控制台

- 聊天页恢复上次选择的“聊天/公众号”分类及各分类最后打开的会话；显式会话链接仍优先。
- 通讯录桌面与手机界面增加联系人、群资料入口；手机布局展示备注、微信 ID 与回复模式。
- 将撤回通知关联到原消息，分别展示自己和对方的撤回状态；历史归档升级时清理重复的原始 XML 通知。

## 升级说明

- 主程序和 SDK 升级到 v0.9.2，core 默认版本仍为 v0.4.5；通信协议未改变。
- 已在运行的 core 保持登录。升级 gateway 前先停止旧 gateway，保留原账号数据目录，并在安装时继续填写该 core **启动时使用的绝对路径**。
- 若在 core 运行期间移动了账号目录，先恢复原启动路径可访问，再复用该进程；要改用新路径，需计划性停止并重新启动 core。仅更新 gateway 不会修改运行中 core 的启动路径。

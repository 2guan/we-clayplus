# we-clay v0.9.1

## 安装体验

- macOS、Linux 和 Windows 安装脚本显示授权、下载、校验、安装等阶段；下载主程序时显示实时进度。
- 进度输出不包含授权 Key 或私有 OSS 的临时签名链接；下载失败仍保留原有安装版本和授权文件。
- 安装时可设置设备显示名称，并由运行入口沿用；省略 Key 文件时可直接在终端隐藏输入授权 Key。

## 兼容性

- 主程序、SDK、gateway 与 core 通信协议保持不变；core 默认版本仍为 v0.4.5。
- 可继续使用原 core 账号目录。已经安装 v0.9.0 的用户重新运行安装命令即可升级；若旧 gateway 正在运行，先停止旧 gateway 后再运行新版本。

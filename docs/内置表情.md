# 微信内置小表情中文、英文与图片对照

这份对照以用户在当前微信界面逐个点出的 **109 个中文名称**为顺序。英文输入码和图片来自 [Emojipedia 微信页面](https://emojipedia.org/zh/wechat)的历史表格；图片由 `em-content.zobj.net` 提供。所贴表格的列标题分别是 Android 微信 **7.0.21** 与 iOS 微信 **8.0.2**，图片路径为 2021 年版本。它们是旧版本的图像示意，不代表当前微信客户端一定使用相同图形。

需要给界面或脚本读取时，可直接使用[同一份 CSV 对照表](内置表情对照.csv)。

中文和英文的对应关系参考了[公开的 Mac 微信 `newemoji-config.xml` 快照](https://gist.github.com/cdpath/2a42edb3f2b81d18de2ae9ed8a3ac48b)及[第三方 Go 映射](https://github.com/WQMLSM/wechat/blob/master/emoji.go)。对同一中文名称出现多个英文别名的情况，优先列 XML 与图片表都存在的代码，并在备注中保留另一映射。表中没有图片的两项不猜测 URL。

这些中文输入码可以作为普通文字发送，和 `message.TypeEmoji` 动态表情包不同：

```go
codes := message.BuiltinEmojiCodes() // 用于选择器或帮助页面
_, err := client.SendText(receiver, "今天状态不错[旺柴][破涕为笑]")
_ = codes
_ = err
```

其中 `[旺柴]` 和 `[破涕为笑]` 已在本项目 Mac 模式下经手机确认显示为内置表情并成功撤回。其余名称来自用户当前微信界面，尚未逐个验证通过 API 发送后的显示行为。代码返回这 109 项的独立副本；不包含图片文件。

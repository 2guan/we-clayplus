# 音乐插件

音乐插件参考 Golem 项目的 `plugins/music`（作者 ovo）迁移点歌解析、QQ 音乐接口、原生音乐 XML 和来源 AppID 数据。原公开服务地址与来源配置保留；默认搜索现使用酷我优先、抖音备用。没有复制 Golem 的独立依赖、编译产物、凭据或账号数据。

## 使用

在插件中心开启“音乐”。仍遵循插件的黑白名单和冷却设置，空黑名单表示全局生效。支持私聊和群聊，例如：

- `点歌 晴天`、`点歌周杰伦`
- `音乐 稻香`、`music bohemian rhapsody`
- `我想听 海阔天空`、`我要听 孙燕姿的歌`
- `来首 陈奕迅`、`给我放一首歌 七里香`、`搜歌 夜曲`
- 群聊默认必须在微信真实 @ 本人后发送以上句式，可在音乐插件配置关闭“群聊触发必须 @ 本人”。手写昵称、@ 他人或 @所有人不能替代；私聊、工作台和定时任务不受此限制。

“我想听故事”“我想听你的声音”等不会作为点歌请求。内置音源返回首个通过音频校验的匹配，发送含歌名、歌手、播放链接的音乐卡片。工作台显示实际音源，可试听并选择卡片、文字链接或音频文件；同一结果提供封面、歌词时才展示。自定义服务保留多结果选择，文字链接模式不要求返回音频地址。

工作台的目标会话优先显示备注、群名或昵称，ID 显示在下方；候选包含名称和 ID，重名会话按具体 ID 区分，预览和发送仍使用 ID。也可直接输入会话 ID。

点歌支持空格、逗号和冒号分隔，例如“点歌，完美的一天”“点歌 孙燕姿 完美的第一天”。明确点歌时，“故事”“秘密”等也可以是歌名；自然聊天“我想听故事”仍不触发。查询比较忽略空白和标点；已核实歌手的组合查询允许长歌名一字差异，指定歌手仍不能被翻唱者替代。已有音频标签时，封面资料继续严格核对实际歌名、歌手和专辑。

“点歌 随便点一首舒缓的”“点歌 推荐一首轻快的英文歌”“来一首治愈的歌”会先使用模型中心对话流水线选出最多三首具体歌曲，再逐首通过既有音源搜索与音频校验，找到可播放结果后只发送一首。模型只提供歌名和歌手，不生成播放地址；没有可用模型或无有效歌曲时明确失败。明确歌名直接搜索，不额外调用选曲模型；歌名与随机词冲突时可用《歌名》指定字面歌曲。

## 接口与配置

默认配置：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `group_mention_required` | `true` | 群聊口令必须真实 @ 本人，可关闭；不影响私聊、预览发送或计划任务 |
| `source` | `auto` | 优先酷我，失败再试抖音；可选 `kuwo`、`douyin`、`custom` |
| `endpoint` | `https://109a.cn/API/qqyy/api.php` | 仅 `custom` 使用，保留 Golem 原调用地址，可修改 |
| `api_format` | `golem` | 仅 `custom` 使用，查询使用 `msg`，响应使用 `code/data` |
| `limit` | `5` | 抖音最多检查的候选数；自定义服务的结果上限，范围 1—20 |
| `send_mode` | `card` | `card` 为原生卡片，`link` 为文字链接 |
| `app_id` | `random` | 从 Golem 原表的 218 项来源中随机选择；可填固定 wx AppID，空值不标来源 |
| `key_env` | 空 | 仅 `custom` 使用的可选 Bearer Key 环境变量名，不直接保存密钥 |

配置页会显示酷我、抖音实际使用的内置地址；这两条地址定义在 `plugins/toolbox/music_sources.go`，目前不通过插件配置修改。自定义地址、接口格式和凭据环境变量仅在选择 `custom` 时显示；切换音源不会清空已保存的自定义配置。

### 组合音源

- [酷我音乐接口](https://109a.cn/api_details.php?id=25)：`GET https://109a.cn/API/kwyy/api.php?msg=<关键词>&a=1&n=1`。实际响应 `code` 为字符串 `"200"`，根字段 `url` 是音频地址。`name` 是专辑目录，不能作为歌名；从最多 64 KiB 的 MP3 头部读取 ID3v2.3/2.4 歌名与歌手，并向酷我公开搜索入口补充完整资料。使用可返回标准 JSON 的移动端搜索参数，核对歌名、实际歌手和专辑后取对应歌名、歌手及封面路径；不会把其它歌手、其它专辑或抖音封面配到当前音频上。无标签且无法核实歌名时明确报错，不再使用“搜索：关键词”冒充歌名。资料接口失败但音频标签完整时，保留已确认的标签。
- [抖音音乐接口](https://109a.cn/api_details.php?id=24)：`GET https://109a.cn/API/dyyy/api.php?msg=<关键词>`。实际响应 `code` 为字符串 `"0"`，`data` 提供 `title`、`url`、`imgurl`，按最后一个 `---` 拆分歌名与歌手。歌名精确匹配优先于歌手名碰巧相同的结果。可能返回翻唱、混音或片段，保留原标签。组合关键词同时按歌名和实际歌手匹配，不把翻唱注释中的原唱当作演唱者；没有匹配项时明确失败，不随意发送其它歌手。

酷我资料请求为 `GET https://search.kuwo.cn/r.s`，使用 `all`、`ft=music`、`mobi=1`、`strategy=2012`、`ver=kwplayer_ar_8.5.5.0`、`vipver=8.5.5.0`、`rformat=json`、`encoding=utf8`、`pn=0`、`rn=20`。读取 `SONGNAME/NAME`、`ARTIST`、`ALBUM`、`web_albumpic_short`，相对封面路径接入酷我自己的图片 CDN；不更换原音频地址。资料读取最多 4 秒，计入单音源时限。

自动模式先搜索酷我并读取音频头验证（包括无 ID3 标签、连续 MPEG 帧的 MP3）；搜索失败、链接失效、内容非音频或超时，才尝试抖音。单音源最长 12 秒，组合搜索最长 25 秒；返回首个可读取结果。只在搜索和音频探测阶段切换，发送卡片后不会因未知回执而换源重发。试听和音频文件发送均支持实际的 MP3 与 M4A。

这两个接口实测无需 API Key；内置请求和媒体读取不携带自定义凭据。`key_env` 只对 `custom` 生效。此次已对真实搜索结果和音频头部进行只读验证，未向真实微信发送测试消息。

### 原 Golem 与自定义服务

切换 `source=custom` 可继续使用原接口：

```text
GET https://109a.cn/API/qqyy/api.php?msg=<经过 URL 编码的歌名或歌手>
```

响应：

```json
{"code":200,"data":[{"song":"歌名","singer":"歌手","url":"https://example.com/song.mp3","cover":"https://example.com/cover.jpg","lyric":"歌词"}]}
```

`url` 同时作为分享地址和音频播放地址；封面、歌词可以为空。程序沿用原始链接，不伪造接口结果。来源表包含公开应用标识及空来源选项，不是登录凭据。随机来源只影响卡片来源标识，不更换搜索服务。

已有自定义服务升级后保留 `endpoint`，自动选择 `custom`；更早版本缺少格式和分享配置时使用旧的 `items` 格式和文字分享。原 Golem 默认地址升级后选择 `auto`，仍保留原地址可手动切回。手动保存过的新配置后续重启不会覆盖。`items` 模式沿用 `q/url/limit` 请求参数和 `items` 数组，字段为 `title`、`artist`、`url`、`media_url`、`cover`、`lyric`，详见 [控制台与 AI](控制台与AI.md)。

## 发送与失败处理

音乐卡片使用已有 SDK 类型 `TypeAppMusic`（4976），外层应用子类型 76，XML 内层类型 3。封面地址同时写入专辑图 `songalbumurl` 与聊天卡片缩略图 `thumburl`；这只保证链接字段完整，不代表手机封面已验证可显示。当前 core 发应用消息入口尚未接入缩略图字节参数，手机仍无图的问题待进一步验证；接收时也兼容只有缩略图字段的音乐消息。网关只构造音乐字段，并进行 XML 转义，不接受网页任意提交应用 XML。core 保持独立，不作修改。发送回执中的消息 ID、原始 ClientID 和创建时间沿用现有归档与撤回链路。

搜索失败或无结果会在执行记录中显示原因，微信触发时也向原会话发送一条失败提示；工作台预览失败只在页面显示。发送回执不完整时标记结果未知，不自动重复发送。失败消息可通过微信模块原有重发入口，从可信归档恢复卡片；结果未知时仍需确认重复发送风险。

网络请求遵守公网地址、DNS、重定向和响应大小校验。系统 DNS 若只返回代理的 `198.18.0.0/15` 虚拟地址，改用固定 HTTPS 解析器 `https://223.5.5.5/resolve` 获取真实公网 IPv4 后连接；不直接放行虚拟地址或任何内网地址。音乐请求使用浏览器形式的 User-Agent 兼容原服务。封面与试听由认证后的本机入口读取，仅允许当前账号的已有卡片或有效工作台预览；浏览器不能通过该入口指定其他地址。资源失效会影响封面或试听，不影响已归档的歌名和歌词。

## 验证范围

离线测试覆盖点歌句式、两源故障切换、实际响应结构、ID3 标签、完整资料核对和错误资料不伪造标题、无标签 MP3 连续帧与 M4A 识别、歌手及歌曲匹配、候选排序、参数编码、来源表完整性、旧配置迁移、XML 转义、卡片预览与发送、失败传播和原始回执的发送→撤回传递；浏览器测试使用 Mock，不调用真实微信或音乐服务。

第三方接口可能超时或返回无结果；其服务可用性、音频链接有效期以及真实微信客户端中的卡片播放效果，需要以实际服务和微信表现为准，离线通过不代表真实微信写操作已验证。

# 新闻插件

参考 Golem `plugins/news`（作者 ovo）补入今日新闻、今日图卦、按日缓存与原能力名称，保留本项目原有 RSS / Atom 阅读、关键词筛选及定时任务。代码许可说明见 [Golem MIT](licenses/Golem-MIT.txt)。不复制 Golem 的模块、凭据、账号数据或运行文件，不修改 core。

## 使用

在插件中心开启“新闻”。默认黑名单，名单为空时全局生效；已有名单与开关保持不变。私聊和群聊均可发送，也支持在群里 @ 本人后使用：

| 指令 | 内容 |
| --- | --- |
| `今日新闻` | 北京时间当天的 60 秒新闻图片，一张 |
| `今日图卦` | 北京时间昨天的图卦，两张，按 1/2、2/2 顺序发送 |
| `新闻` | 跟随配置中的默认新闻类型 |
| `RSS新闻` | 配置的 RSS / Atom 源，输出标题与链接 |
| `新闻 科技`、`RSS新闻 体育` | RSS 标题关键词筛选 |

新安装默认图片新闻；升级前已有 RSS 地址且没有明确选择默认类型的，保留 RSS 为默认。明确的“今日新闻”“今日图卦”始终读取相应图片，不受 RSS 默认影响。图片新闻不进行关键词筛选。

微信口令按同一账号、会话和新闻类型分别冷却，沿用配置的秒数（默认 30 秒）；刚请求今日新闻后仍可立即请求今日图卦或 RSS。`新闻` 跟随默认类型，与该类型的明确口令共用冷却；RSS 的不同关键词共用 RSS 冷却。冷却状态持久化，拦截不延长等待时间，执行记录显示“冷却中”和对应类型。

## 数据源和配置

沿用 Golem 原地址：

- 今日新闻：`https://cdn.jsdmirror.com/gh/vikiboss/60s-static-host@main/static/images/{date}.png`，`{date}` 为 `YYYY-MM-DD`。
- 今日图卦：`https://penti.5aihj.com/{month}/tugua/{date}{index}.jpg`，读取昨天，`{month}` 为 `YYYYMM`、`{date}` 为 `YYYYMMDD`、`{index}` 为 1 和 2。

配置中的 `today_template`、`diagram_template` 可修改地址；`default_mode` 为 `today`、`diagram` 或 `rss`。`endpoint`、`key_env`、`limit` 仍用于 RSS；公开图片请求不携带 RSS 凭据。

每张图片最多 16 MiB，仅接受可解析尺寸的 PNG / JPEG，最大 5000 万像素、单边最多 50000。公网地址、DNS、重定向及读取超时沿用统一检查；响应头宣称是图片但内容为 HTML 时拒绝。当天资源尚未发布时明确失败，不拿昨日图冒充今日新闻。

图片缓存在本次服务进程内，新闻和图卦各保留一份日期及数据源匹配的完整内容。跨日或修改地址后重新获取；失败、半组图卦不写入有效缓存。重启后重新获取。系统设置清理文件与媒体缓存时也清空此公开图片缓存；有效预览与已发送图片引用受到保护。

## 工作台与定时任务

工作台选择新闻类型后生成预览，点击图片可查看原图；预览不会发送微信消息。确认发送复用已保存的图片，不重新抓取。图卦两张均准备成功后才开始发送，间隔一秒；每张发送前重新检查账号、插件开关、名单及任务版本。

定时任务的“计划新闻类型”可分别选择今日新闻、今日图卦和 RSS，或跟随插件默认。图片日期以执行时的北京时间计算；计划本身的时区仍按任务配置。已有 RSS 查询任务保留原查询语义。

准备失败时在记录中显示原因；微信指令触发时回复失败提示。发送结果未知或第二张失败时记录已完成张数，不自动重发整组；可在微信模块按单条消息核对和处理重发。

## 兼容能力

保留 Golem 的能力名称，通过现有插件管理器调用：

```json
{"capability":"news.today","args":{"receiver":"接收会话ID"}}
```

```json
{"capability":"news.diagram","args":{"receiver":"接收会话ID"}}
```

`receiver` 必须是本机已知联系人或群；仍检查“新闻”插件开关与黑白名单，成功返回 `none`，图片通过原消息链路发送。能力调用不是任意 URL 或任意 XML 发送入口。

## 验证范围

离线测试验证北京时间日期、缓存换日、缓存完整性、非图片与私网拒绝、RSS 配置保留、预览不发送、双图顺序、第二张发送前权限复查、预览媒体保护和能力调用边界。浏览器测试使用 Mock，不访问真实微信和新闻源。

真实数据源已做只读图片获取验证；未向真实微信发送测试消息。离线测试及图片下载成功不代表真实微信发送效果已验证。

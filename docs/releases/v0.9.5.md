# we-clay v0.9.5

本版合入 [PR #19](https://github.com/we-clay/we-clay/pull/19)，主要改进群聊 AI 回复、微信原生互动与控制台通知展示。core 没有改动；已有安装的 core 版本和微信账号目录继续沿用。

## 群聊回复

- 把同群中尚未生成回复的连续消息按停顿合并处理，保留发言人的真实身份和互动关系，减少逐句追答、重复回复及角色混淆。
- 在模型输出和实际发送前检查回复计划；无需回复时只记录原因，不把沉默标记或规划文本发到微信。
- 普通 AI 回复可发送微信原生 @、引用及二者组合。发送前核对真实群成员与消息所属会话，并检查发送回执，拒绝失效目标和跨会话引用。

## 插件与消息展示

- 群聊关键词插件默认要求真实 @ 当前账号，各插件仍可独立配置触发条件。
- 点歌支持更宽松的分隔方式、指定歌手和风格随机请求；工作台按音源显示配置，并优先使用群名和昵称。
- 控制台展开邀请入群通知、显示语音和视频通话状态，并从已有加密原文恢复旧记录的展示。

## 升级

先在旧 gateway 的终端按 Ctrl+C，等待它退出。原来使用默认安装目录的 macOS/Linux 用户，在 v0.9.5 私有 OSS 发布完成后运行：

```sh
curl -fsSL https://nww.hihfy.com/we-clay-auth/install.sh | bash -s -- --restart
```

原来传过 `--data-dir` 的用户，升级时继续传入同一个路径。安装器复用已保存的授权 Key、core 版本和微信账号目录；只更新 we-clay 不需要传 `--core-version`，也不会重建微信设备。Windows 用户用现有 PowerShell 安装脚本加 `-Restart`，自定义过目录时继续传入原 `-DataDir`。完整步骤见[一键安装与升级](../一键安装.md#已安装用户维护)。

## 验证与限制

PR #19 已通过完整 Go 测试、`go vet ./...`、相关包竞态测试、前端构建和相关 Playwright 用例；发布流水线还会执行离线检查、六平台编译及私有 OSS 上传回读。原生 @、引用及其发送后撤回组合尚未逐项真机验收；微信实际发送仍以服务端回执和手机端观察为准。core 登录后的设备安全质询应答不在本版范围内。

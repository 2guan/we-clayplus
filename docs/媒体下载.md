# 统一媒体下载

直接接入与插件都沿用 `Message.Download`：

```go
stream, err := client.Message.Download(msg)
if err != nil { return err }
defer stream.Close()
_, err = io.Copy(destination, stream)
return err
```

图片、视频等沿用 core 的 gRPC 下载。表情包由 we-clay 识别微信 CDN 并下载，支持已验证的 GIF、PNG，以及 JPEG/WebP 文件类型。不会修改 GIF 动画帧。下载受超时、20 MiB 大小、域名与目标 IP 限制约束；重定向同样校验，失败信息不暴露带鉴权参数的原始 URL。加密或未知格式会明确报错。

robot 只负责私有缓存、消息所属账号、HTTP Range 和界面展示。图片、视频、表情不再分别在 robot 实现 CDN 协议。已经缓存的媒体可以离线查看；未缓存内容需要有效的 Client。

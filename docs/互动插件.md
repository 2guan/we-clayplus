# 互动插件使用说明

本次新增 13 项独立插件，统一从「插件中心」配置和打开工作台。真实模式默认关闭。名单默认黑名单，启用后空黑名单全局生效，填入会话 ID 则排除这些会话；可手动切换白名单，仅允许名单内对象。不改变已有海龟汤配置，不修改 core。

## 报名和好友私聊

谁是卧底、狼人杀、阿瓦隆、剧本杀、默契测试需要秘密通道：

1. 群内开局后，参与者在原群发送「加入」。房主自动报名。
2. 参与者需要是当前微信账号的好友，并私聊「确认入局 对局码」。程序同时检查原群报名成员 ID、好友记录和实际私聊入站；昵称和对局码不能代替身份校验。
3. 本人通过私聊回发一次性收件码；玩家回复「确认收件 对局码 收件码」才算完成双向可达性确认。不要把收件码发到群里。
4. 人数及所有玩家确认满足后，由房主在原群发送「开始游戏」。指定人数时需恰好达到该人数。
5. 所有秘密操作使用「游戏 对局码 操作内容」，例如「游戏 a1b2c3d4 验 3」。多人参与多个群局时不会串线。
6. 秘密消息逐条确认发送，身份全部发放完成后才发送公共开局通知。失败或未知发送会阻塞该会话后续游戏操作，先在工作台处理。

公开副本和跑团不要求加好友；群内报名后直接由房主开局。私聊副本可单人直接开始。私聊默契测试可由发起者分享对局码给自愿参加的好友；对方发送「加入 对局码」，再私聊确认，最后发起者开始游戏。

## 固定规则

### 谁是卧底

4—7 人一名卧底，8—12 人两名卧底；模型生成两个相近但不同的词，程序随机分配。每位在场玩家每轮描述一次，随后投票，不得投自己或已出局者。平票重投一次，再平票无人出局。卧底被投出后可私聊猜平民词，猜中直接获胜；否则继续结算。卧底全部出局则平民获胜，卧底人数达到在场平民人数则卧底获胜。

### 狼人杀

支持 6—12 人基础板子。包含两名狼人、预言家、女巫，其余村民；9 人起三狼，8 人起猎人，10 人起守卫。身份由程序随机分配。

狼队通过好友私聊中继交流，所有在场狼人提交刀人选择后结算；多数选择为准，平票按玩家序号决定。之后预言家、女巫、守卫私聊行动。女巫每夜最多一种药，非首夜不能自救；守卫不能连续守同一人，同守同救仍受刀伤。猎人被毒出局不能开枪；被刀或投出可开枪一次。白天由房主结束讨论再投票；房主即使出局仍可主持进入投票。平票重投一次，再平票无放逐。

狼队人数达到好人人数时狼人获胜；狼人全部出局则好人获胜。不是所有第三方板子或扩展角色的通用实现。

### 阿瓦隆

5—10 人。邪恶人数分别为 2、2、3、3、3、4。基础角色梅林、刺客、忠臣、爪牙；7 人起加入派西维尔和莫甘娜。派西维尔只看到梅林/莫甘娜两个候选，不能区分。

按人数和任务轮次确定队伍人数，严格多数批准才通过，平票视为反对；连续五次组队被拒绝邪恶获胜。好人只能提交任务成功。7 人及以上第四次任务需要两张失败票，其余一次失败票即任务失败。三次任务失败邪恶获胜；三次成功进入刺杀，命中梅林邪恶获胜，否则好人获胜。

### 剧情、问卷和冒险

剧本杀开局固定角色、线索、凶手和答案快照；公开开场不包含程序保存的秘密字段，私有线索只向所属角色发放。最终所有人指认后揭晓。

默契测试按本题最多相同选项人数计算群体共同选择指数；性格测试按选项 0—3 分累积，输出随性探索、平衡观察或果断行动的娱乐分类。两者不是关系判断或专业心理测评。

冒险由模型一次生成固定地图，程序维护所有连接、调查、敌人生命、物品与胜负。角色生命 10，擅长技能检定 +2；d20 检定，战斗命中造成 d6 伤害，失败承受 d4 伤害；物品消耗给下一次检定 +3；每位玩家在每个地点可休息一次，恢复 3。完成全图调查且击败所有敌人通关，全队倒下失败。地图和数值以已保存快照为准，不接受模型临时改规则。

心动剧场与电台本次提供文字交互和独立剧情记录。尺度在配置中选择，默认清水；成人暧昧仅供成年用户主动选择，不含露骨内容。语音不是本次自动开启的能力。

## 模型和失败处理

复用模型中心流水线、故障切换、提示词防护与上下文清理。全部候选失败后完整流水线自动再试一轮，JSON 结构或规则参数不合法也视为失败。私有模型资料不会出现在公共任务输入/结果中；模型不获得真实微信操作工具。

工作台的「回合与重试」显示失败原因。未发送的失败回合可以人工重试，已经提交的游戏状态和已发送条目不会再次执行。发送结果不明标为「发送结果未知」，禁止直接重试；在微信核实当前条目已发送后才可确认并继续剩余条目。无法核实则结束该局，不冒险重复发身份。

服务重启保留加密存档；生成中断改为可人工重试，发送中断改为未知，均不自动重发。账号、epoch、会话名单、好友关系、来源消息撤回和对局版本在执行时重新校验。

## 群日报与群梗

日报、周报只读取本群有效文字/引用归档，排除撤回、删除、系统通知、失败发送、秘密游戏消息和插件自己的日报输出。公开游戏明确标记，不能混作现实事实。输出必须有有效来源编号；发送前再次校验来源。默认上限 1000 条，可配置至 20000 条；模型固定输入超过预算时明确失败，不静默删资料。本次为手动生成，不自动启用定时发送。

收藏群梗必须引用本群有效的真实参与者消息。模型仅生成待审核说明，后台确认后才能查询和回顾。可编辑说明并重新审核、拒绝、删除；同一来源不会反复自动提交，来源撤回/删除后停止使用。原始聊天归档不因删除群梗而删除。

## 数据与验证边界

新表 `play_games`、`play_turns`、`play_memes`、`play_daily` 使用现有本地密钥加密正文，按微信账号隔离。后台秘密资料仅管理员可读。公开游戏消息进入普通上下文并标记为虚构；秘密消息排除普通上下文、模型消息检索与报告输入；所有互动插件消息不作为长期记忆来源。

离线规则、队列、模型、API 和浏览器测试使用虚构数据。没有因此执行真实账号的发消息、加好友或其他微信写操作；真实好友可达和多客户端表现仍需启用后验收。关闭对应插件可停用，不影响原始聊天归档。

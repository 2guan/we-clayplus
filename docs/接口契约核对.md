# 接口契约核对（v0.5.2）

本轮针对 v0.5.1 撤回修复暴露出的跨层问题，检查当前 52 个已接通方法的 gateway 参数、core 接收格式和 SDK 回执映射。对照现有 core 接口源码，测试使用本地模拟 gRPC 服务，不连接真实微信；76 个占位方法保持占位。

## 已修复

| 问题 | 修复与验证 |
| --- | --- |
| 好友备注、申请/验证、标签等接口可能丢掉业务失败码；空响应被当成默认成功 | 在 core 回执解析处检查业务状态及 oplog 命令状态；需要结构化回执的接口拒绝 `null`、缺失状态和非零业务码。跨联系人、群聊、朋友圈、标签、收藏容量、小程序记录和账号查询测试失败回执，确保只调用一次。 |
| 搜索后缺少申请好友所需的票据，缺失昵称还可能触发空指针 | `Contact` 增加 `V1`、`V2`；保留原方法签名和字段编号。通过直接调用和插件 gRPC 验证搜索→申请的票据、场景和操作值；空结果返回 `nil`。 |
| 收藏同步把收藏类型写成收藏 ID，丢掉来源信息与未识别命令 | `Item` 新增 `Type`、`ClientId`、`SourceType`、`SourceId`。没有真实收藏 ID 时 `Id` 为 0；遇到未支持命令返回错误，不把新游标交给调用方。非空合成数据和 protobuf 往返验证字段。 |
| CDN 空上传回执、JSON 回执可能被当成有效媒体 | 检查上传后的文件 ID、密钥、长度或图片 URL；下载要求非空 `application/octet-stream`。测试图片/视频上传→下载、封面、朋友圈图片，以及错误媒体响应。 |
| 添加标签成功回执缺少标签 ID，取消点赞嵌套操作失败仍可返回成功 | 缺少标签 ID 返回结果未确认；取消点赞检查操作列表中的失败码。 |
| 群成员缓存初始化直接访问第一条结果 | 空联系人列表、空成员结构使用安全读取，避免未返回成员时数组越界或空指针。 |

写入成功与否不确定时，不自动重发。上层收到 `err` 应保留错误并核对实际状态，不能把错误统一处理成再次发送。

## 保留的正常行为

- 指定好友朋友圈的 `BaseResult.Code == 207` 表示到达分页末尾，保留返回内容与状态，不当作调用失败；只在该接口放行。
- 开始/停止输入是无返回数据的操作，合法的 `data: null` 继续有效。
- 联系人/群备注和群通讯录保存由 core 验证命令回执并读回。有些 packed 命令状态经过 core JSON 转换后不再包含标量 `code`，这些特定路由允许已验证的单命令回执，不将该例外扩大到其他操作。
- 修改群名遇到上述单命令回执时，gateway 额外查询一次群联系人详情，只有群 ID 和群名匹配才返回成功；不重复写入或自动回滚。读回失败或不匹配时返回结果未确认。
- 64 位朋友圈 ID、分页 ID 和同步 key 原样传递；key 中的 `+`、`/`、`=` 不被查询参数编码破坏。
- 联系人查询、群成员查询中依赖缓存的接口仍返回缓存，不承诺每次都联网刷新。

## 核对范围

| 能力域 | 已接通方法 | 本轮重点与现有边界 |
| --- | --- | --- |
| Message | Send、Forward、Revoke、Download | 路由、JSON/multipart、原始 XML、撤回三项回执、附件分块、媒体二进制。沿用发送/转发/撤回/文件下载测试；视频与表情的完整撤回回执仍不可保证。 |
| Contact | Get、List、GetSelf、GetOwner、Search、SetRemark、AddFriend、VerifyFriend | 前四项为缓存/配置；其余核对备注 JSON、搜索参数、票据与业务回执。Search 的旧签名没有 error，失败或无结果返回 nil。 |
| Chatroom | Create、GetInfo、GetQRCode、InviteMember、SetName、SetAnnouncement、SetRemark、Save、SetAdmin、ListMembers、GetMember、GetMembersDetail | 群名/备注/保存使用 query，公告/成员操作使用 JSON；群详情混合远端公告与联系人缓存，其余部分成员查询依赖缓存。邀请回执不代表已入群。 |
| Moments | Timeline、UserPage、Detail、Like、Unlike、Post、Upload、Sync | 大整数 ID、分页、正常末页、上传字段、状态码。Post 接收 core 所需的朋友圈对象描述；Sync 的 key 会传到 core，但 core v0.3.0 实际使用会话内同步游标。 |
| CDN | UploadImage、UploadVideo、DownloadImage、DownloadVideo、UploadMomentsImage、DownloadVideoCover | multipart 参数、上传后必需字段、SDK 映射和字节回执。CDN 上传本身不代表消息已发送。 |
| Favor | GetInfo、Sync | 容量字段、Base64 游标、类型/来源映射；真实非空收藏同步尚未验收，未知命令不跳过。 |
| Label | List、Add、Delete、Update、ModifyContactLabels | label_name、label_ids、标签 ID、业务状态；空 label_ids 保留清空含义。 |
| Miniapp | GetRecord | 路由与记录列表、基础状态映射；其他方法保持占位。 |
| Report | StartTyping、StopTyping | receiver 查询参数与无数据成功回执。 |
| User | GetProfile、GetQRCode、GetSafetyInfo、GetBoundHardDevices | 只读路径、二维码 style 参数与基础状态；安全/资料写入保持占位。 |

## 升级

```sh
go get github.com/we-clay/we-clay@v0.5.2
```

重新编译应用；需要新增字段的插件也重新编译。没有改变原字段编号、RPC 名称或 corewire 协议，core v0.3.0 无需升级。

该检查降低适配层把错误当成功、把字段传错的风险，不代表当前发布版的所有接口和参数组合都完成真机验收。历史范围继续以 README 中的逐项说明为准。

# we-clay v0.9.4

此版本承接 v0.9.3 的全部功能变更。v0.9.3 标签的 Ubuntu 发布测试因缺少中文字体失败，未上传 OSS，也未切换线上安装脚本；v0.9.4 在发布测试前安装 Noto CJK 字体。

## 安装与微信连接

- 新安装默认使用已发布的 core v0.4.6。该 core 版本改进授权 Key 获取私有 OSS 下载地址及发布清单检查；它不包含设备安全质询的自动应答。
- 控制台的“微信连接”页面可以查看二维码、提交登录验证，并启停由当前安装管理的独立 core。停止 core 不调用微信退出登录，也不删除账号目录。
- 安装器支持在升级时受控切换 core 版本、授权 Key 和设备名称。先下载并校验目标程序，再核对旧进程身份并停止；旧 gateway 必须先正常退出。原账号目录保持不变。

## 控制台与 AI

- 控制台改进消息增量存储、缓存清理、群聊回复调度及聊天记录展示；增加大附件上传配置。
- AI 增加可审核的长期记忆、失败回复重试、微信操作入口和互动插件。真实账号写操作仍受配置与确认流程控制；离线测试通过不代表所有微信账号及模型供应商已真机验收。

## 已安装用户升级

先在旧 gateway 的终端按 Ctrl+C，等待退出。确认 core v0.4.6 与本版本主程序均完成私有 OSS 发布后，在原安装目录执行：

```sh
curl -fsSL https://nww.hihfy.com/we-clay-auth/install.sh | bash -s -- \
  --data-dir "$HOME/Documents/.we-clay" \
  --core-version v0.4.6 \
  --restart
```

命令中的目录是示例；自定义安装目录须填写原路径。安装器读取已保存的授权 Key、设备名称和微信账号目录。**只升级 we-clay 时不会自动切换已有 core**；同时升级 core 才显式传 `--core-version`。旧版安装若曾在运行入口额外指定 core 版本、地址或账号目录，按[一键安装与升级](../一键安装.md#已安装用户维护)补齐相应 `--previous-*` 参数。Windows 用户使用同一安装脚本的 PowerShell 版，指定原 `-DataDir`、`-CoreVersion v0.4.6` 和 `-Restart`。

## Linux 字体依赖

词云、文字表情、日报和离线 News 图片使用本机中文字体。Ubuntu 24.04 可安装 `fonts-noto-cjk`，或在控制台配置可读取的 TTF/TTC 字体路径。发布流水线也会安装同一字体，以运行 News 图片测试。

## 已知限制

core 对登录后的设备安全质询仍缺少完整应答；本版本不能据此保证微信安全验证通过，也不能把约 20 分钟后掉线归因于某个未证实的质询。登录和群聊等能力仍受微信服务端状态约束。
